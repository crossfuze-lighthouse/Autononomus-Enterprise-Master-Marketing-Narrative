# Crossfuze campaign plan — portable pack

## Open the campaign

Extract the ZIP first, then open `index.html`. Keep the `assets` folder beside it.

## Publish on GitHub Pages

1. Upload the CONTENTS of this folder to your repository: `index.html`, `assets`, `.nojekyll` and this README. Do not upload the ZIP itself as the website.
2. In repository Settings → Pages, select deployment from the branch containing these files and the folder containing `index.html` (normally `/ (root)`). Save.
3. Once GitHub finishes deployment, open the Pages URL. Test Guides & tools and each document card.

All packaged asset links are relative, so they work under a project URL such as `https://USERNAME.github.io/REPOSITORY/` without editing.

## Links and updates

The AI Readiness Gap page, tools hub and assessment page remain external links to crossfuze.com and require internet access. They are not offline copies.

To replace an included guide later, retain its filename in `assets`. If you change a filename, update matching `href` values in `index.html`. Filenames are case-sensitive on GitHub Pages. There are no local computer paths or private ChatGPT URLs used as document links.
